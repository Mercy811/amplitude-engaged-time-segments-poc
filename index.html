Proposed data path

Separate page existence from attention updates

① Browser SDK

Calculates engaged deltas under a stable Page View ID. Emits lifecycle checkpoints on cadence, hide, navigation, and best-effort exit.

→
② Ordinary ingestion

Accepts an immediate Page Viewed plus idempotent append-only segment events. No two-hour mutable pending record.

→
③ Metric middleware

Deduplicates segment IDs and sums deltas by Page View ID into a native engaged-time metric.

What this buys

Immediate Page Viewed queryability, correct page attribution, active-attention semantics, incremental last-page protection, and a natural real-time metric.

What it costs

More internal events, aggregation middleware, idempotency rules, and a bounded tail loss after the most recent checkpoint if every exit/replay mechanism fails.
